# Operator Covenant

## 1. Introduction

The Operator Covenant is the foundational ethical and operational contract between SELENE OS and its human operators. SELENE is engineered as a cognitive multi-agent operating system, processing tasks across 10 architectural layers. With such capabilities comes the need for an absolute, verifiable commitment to safety, transparency, and human agency.

This document outlines the philosophy, responsibilities, system guarantees, and ethical constraints governing SELENE's operation.

## 2. Design Philosophy

SELENE is designed not as an autonomous sovereign entity, but as a **cognitive amplifier** that operates under the explicit authority of its human user. 

- **Agency vs. Autonomy**: SELENE possesses agency (the ability to act to achieve goals) but not autonomy (the right to determine its own goals without oversight).
- **Default-to-Safe**: In conditions of uncertainty or boundary conditions, SELENE degrades gracefully and requests Human-in-the-Loop (HITL) intervention via Layer 8 Governance.

## 3. Core Tenets

1. **Absolute Transparency**: Every action, intent decomposition, and plan generated by SELENE must be inspectable.
2. **Auditability**: Post-hoc analysis via Replay Forensics is guaranteed. No hidden state transitions are permitted.
3. **Human Override**: The human operator retains the unalienable right to abort, modify, or pause any active operation.
4. **Fail-safe Defaults**: Operations that mutate critical system states or data must default to requiring explicit authorization (HITL Mutation Locks).

## 4. System Guarantees

SELENE promises the following technical guarantees to the operator:

### 4.1 Governance (Layer 8)
- **SSRF Protection**: All network egress points strictly validate target URIs against a known-good configuration to prevent Server-Side Request Forgery.
- **Mutation Locks**: High-risk system changes (e.g., recursive file deletions, root-level package installations) cannot proceed without operator cryptographic/session approval.

### 4.2 Cognitive Assurance (Layer 6: Critic Agent)
Before critical execution steps, the Critic agent validates the proposed plan.
If the plan violates DAG dependency constraints, capability boundaries, or cognitive verifiable criteria:
The system halts execution and escalates to the repair loop or operator.

### 4.3 Execution Boundaries (Layer 7)
All untrusted code executes inside the E2B microVM sandbox (`backend/governance/plugin_sandbox.py`), ensuring complete isolation from the host OS. Local subprocess fallbacks are strictly timed out (30s default) and sandboxed via cgroups.

## 5. Operator Responsibilities

While SELENE ensures systemic safety, operators agree to:
- Review HITL prompts diligently rather than auto-approving.
- Maintain secure access controls to the Layer 0 (Ingress Router) endpoints.
- Regularly review Trust Incident logs to fine-tune Dynamic Embedding Profiles (Layer 2).

## 6. Escalation Paths

When SELENE encounters a scenario violating constraints:
1. **Soft Halts**: Task execution pauses; an asynchronous prompt is sent via WebSocket to the frontend.
2. **Hard Halts**: Critical errors (e.g., SSRF attempts) trigger an immediate abort, discarding working memory and logging a Trust Incident.
3. **Dead-letter Queue**: Failed critical state transitions are dumped to the `selene_dlq` Redis queue for forensic review.

## 7. Data Handling Principles

Memory stratification (Layer 9) governs data lifecycle:
- Working memory (≤1hr)
- Episodic memory (≤24hr)
- Semantic memory (≤7d)
- Procedural memory (≤30d)
- Archival memory (>30d)

All data undergoes exponential decay: $S_{t} = S_0 \times \exp(-\lambda \cdot \Delta t)$, allowing SELENE to gracefully "forget" stale or irrelevant data unless actively reinforced by the operator.

## 8. Ethical Constraints on Autonomous Actions

SELENE is strictly prohibited from:
- Circumventing built-in API rate limits (Layer 0).
- Modifying its own core operational logic (`core/orchestrator.py`, `core/graph_nodes.py`) without a developer HITL lock.
- Initiating outbound communications to unverified third parties.
